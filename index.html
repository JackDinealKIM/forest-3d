    산림공공데이터 활용 사례 · 서비스형

    숲나침반 3D

    산림청 산림공공데이터 5종을 실제 지형 위에 올려, 전국 산림휴양 자원을 한 화면에서 비교·탐색하는 웹 서비스입니다. 설치 없이 브라우저에서 바로 동작하며, 서버·유료 API 없이 정적 호스팅으로 운영됩니다.

    활용한 데이터와 방식

    • 전국휴양림표준데이터(표준데이터) — 186개 휴양림의 좌표·면적·수용인원·입장료·숙박가능여부·주요시설·관리기관·문의를 지도 표식과 상세 카드로
    • 숲나들e 100대명산 정보(CSV) — 100개 산의 좌표·높이·난이도·산행시간·산행코스·교통을 표식과 상세로
    • 전국 치유의숲 좌표(SHP 공간정보) — 38개 치유의숲 좌표를 지도에 투영
    • 국가숲길 코스(GPX 54트랙) — 실제 GPS 궤적을 지형 위 3D 라인으로 그리고 구간 거리·누적 상승·고도 프로필을 계산
    • 전국보호수표준데이터(표준데이터) — 9,945그루 노거수의 수종·수령·규격·소재지를 레이어로, 300년 이상 필터

    파일데이터(CSV·JSON·SHP)와 공간데이터(GPX)를 내려받아 브라우저에서 직접 파싱합니다. 좌표계가 다른 SHP(UTM-K)는 WGS84로 변환했고, 등산로·산 정보는 원본 좌표를 그대로 씁니다.

    활용 내용과 효과

    • 흩어져 있던 4개 사이트를 한 화면으로. 숲나들e·산림청·지자체 자료를 각각 검색해야 했던 휴양림·명산·치유의숲·숲길을 한 지도에서 함께 비교합니다.
    • “어디로 갈까”를 지도 위에서 5초에. 시도·숙박가능·입장료 무료·난이도·보호수 수령 필터로 조건에 맞는 숲만 남기고, 표식을 누르면 원본 값이 그대로 열립니다.
    • 거리·고도를 실제 지형으로. 실제 표고(DEM) 위에 표식을 올려 해발·산세를 눈으로 확인하고, 숲길은 구간 거리와 고도 그래프까지 자동 계산합니다.
    • 아이와 함께 가는 가족에게. 숙박 가능한 휴양림과 난이도 낮은 명산을 한 번에 걸러 가족 나들이 후보를 좁힐 수 있습니다.
    • 운영 부담 0원. 정적 파일만으로 동작해 서버·API 키·유지비가 없고, 스마트폰 브라우저에서도 같은 화면을 씁니다.

    데이터 이용자 관점의 개선 아이디어

    • 등산로 표준데이터에 좌표를. 전국등산로표준데이터(404개 노선)는 산명·난이도·거리는 있지만 경로 좌표가 없어 지도에 그릴 수 없습니다. GPX·SHP 링크 컬럼을 표준 항목으로 넣어 주시면 노선 단위 탐색이 가능해집니다.
    • 휴양림 표준데이터의 좌표·갱신 정합성. 186건 중 일부는 좌표 정밀도가 낮거나 갱신일이 오래되어, 위치 정확도 확인(지오코딩 검증)과 기준일자 필수화가 필요합니다.
    • 데이터 간 식별자 연결. 휴양림·명산·숲길이 서로 다른 코드 체계를 써서 같은 숲을 함께 묶기 어렵습니다. 기관 코드 체계를 공유하면 “이 산 근처 휴양림·숲길” 같은 결합 서비스가 쉬워집니다.
    • 실시간 정보의 파일 제공. 산불·산사태·입산통제 정보가 API 키 발급 없이도 파일로 주기 갱신되면, 본 서비스처럼 키 없는 정적 서비스에서도 안전 정보를 함께 보여줄 수 있습니다.

    숲나침반 3D 사용법

    산림청 산림공공데이터로 만든 전국 산림휴양 탐색 지도입니다.

    1. 지도를 돌려 보세요. 드래그로 회전, 휠·두 손가락으로 확대합니다.
    2. 표식을 누르면 실제 공개데이터 값(시설·요금·난이도·산행코스·수령)이 열립니다.
    3. 왼쪽에서 레이어와 시도를 좁히면 지도와 목록이 함께 걸러집니다.
    4. 국가숲길은 실제 GPX 트랙을 지형에 얹었습니다. 눌러서 코스별 거리·누적 상승·고도 그래프를 보세요.
    5. 내 주변은 브라우저 위치 권한을 허용할 때 50km 안의 숲을 찾아 줍니다.

    데이터 기준일은 항목별로 표시되며, 원본은 공공데이터포털에서 갱신됩니다.
