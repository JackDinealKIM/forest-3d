# 숲잇다 (Forest Link) — 3D 프로토타입

「숲잇다」는 2026년 산림복지 국민제안 공모전(한국산림복지진흥원) 출품 제안의 설명용 시뮬레이터입니다.
AI가 만든 산림복지 처방(숲잇기 코드)이 예약·참여·효과 기록까지 이어지는 흐름을 화면으로 보여줍니다.

- 정적 파일만으로 동작합니다(서버·DB·API 키 없음). three.js는 로컬 번들.
- 처방 입력을 바꾸면 코드·프로그램·코스·8주 효과 예측이 실시간으로 바뀝니다.
- 상단 장소 전환: 치유의숲 / 도시숲 / 도서관 마당
- URL 해시로 상태 고정: `#goal=sleep&mobility=wheel&place=living`

본 페이지는 제안 설명용 프로토타입이며 실제 기관 시스템·데이터와 연동되어 있지 않습니다.
