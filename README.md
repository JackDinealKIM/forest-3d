# 숲나침반 3D — 전국 산림휴양 자원 3D 탐색

산림청 산림공공데이터 5종을 **실제 지형(표고) 위에** 올려, 전국 자연휴양림·100대명산·치유의숲·국가숲길·보호수를
한 화면에서 비교·탐색하는 정적 웹 서비스입니다. 서버·DB·유료 API 키 없이 브라우저에서 바로 동작합니다.

## 주요 기능

- **표식 클릭 → 3D 이름 배지 + 상세 카드**: 지도 위 표식 어디를 눌러도(휴양림·100대명산·치유의숲·보호수·국가숲길) 그 지점 위에 이름 배지가 뜨고, 원본 값이 상세 카드로 열립니다. 보호수 9,945그루도 개별 클릭됩니다.
- **반경 연계 탐색 링**: 표식을 고르면 지형을 따라 반경 20km 링이 퍼지고, 그 안의 휴양림·명산·치유의숲·보호수가 상세 카드에 거리순으로 정리됩니다(10·20·50km 전환).
- **국가숲길 3D 코스 비행**: 코스 상세의 `🛩 3D 코스 비행`을 누르면 실제 GPX 궤적을 따라 카메라가 날며 현재 고도·진행 거리·남은 거리·고도 프로필 커서가 실시간으로 갱신됩니다(일시정지/종료, ESC).
- **분위기·조명 모드**: 맑은 낮 / 황금 노을 / 산림 안개(100m 등고선 강조) 3가지로 지형의 입체감을 바꿔 봅니다.
- 레이어 토글·시도 필터·조건 필터·검색·카메라 프리셋·내 주변(50km).

## 구성

```
index.html          화면(레이어 패널·상세 카드·데이터 출처 모달)
styles.css          디자인(다크 포레스트 테마, 모바일 바텀시트)
app.js              Three.js 지도 엔진(지형·표식·숲길·필터·검색·상세)
vendor/three.min.js three.js r158 (로컬 번들, CDN 의존 없음)
data/hyuyang.json   자연휴양림 186건
data/myeongsan.json 100대명산 100건
data/healing.json   치유의숲 38건
data/trees.json     보호수 9,945그루 (압축 배열)
data/trails.json    국가숲길 6개 숲길·54개 트랙 GPX 단순화 궤적 + 고도
data/terrain.b64    표고 격자 640×640 (Uint16, little-endian, base64)
data/terrain_meta.json 지형 경계(lat/lon)와 격자 크기
```

## 사용한 산림공공데이터 (모두 공공데이터포털, 무료·이용허락범위 제한 없음)

| 데이터 | 제공 | 원본 | 사용한 값 |
|---|---|---|---|
| 전국휴양림표준데이터 | 산림청·지자체 | data.go.kr 표준데이터 15013111 | 휴양림명·시도·구분·면적·수용인원·입장료·숙박가능·주요시설·주소·관리기관·전화·홈페이지·위경도 |
| 숲나들e 100대명산 정보 | 산림청 국립자연휴양림관리소 | 파일데이터 15112801 (CSV) | 명산명·소재지·높이·난이도·산행시간·산행코스·교통·선정이유·위경도 |
| 전국 치유의숲 좌표 | 산림청 | 파일데이터 15110279 (SHP/UTM-K) | 치유의숲명·권역·주소·전화·홈페이지·국립/공립·좌표 |
| 국가숲길 코스 | 한국등산트레킹지원센터 | 파일데이터 15108080 (GPX 56개 중 유효 54개 트랙) | 실제 GPS 궤적 → 거리·누적 상승/하강·고도 프로필 |
| 전국보호수표준데이터 | 산림청·지자체 | data.go.kr 표준데이터 15013194 | 수종·유형·수령·높이·가슴높이둘레·소재지·좌표 |

- 지형 표고: SRTM 기반 Terrarium 표고 타일(줌 8, 36타일)을 640×640 격자로 리샘플링해 사용했습니다.
  대한민국 산림 데이터가 대상이므로 일본 열도 구간은 바다로 마스킹했습니다.
- SHP는 UTM-K(EPSG:5179) → WGS84로 변환, GPX는 30m 간격으로 단순화(원본 16.4만 점 → 약 3만 점)했습니다.
- 표고는 3배(수평 1단위 ≈ 1.6km, 수직 1m = 0.016단위) 과장해 산줄기가 읽히도록 했습니다.

## 로컬에서 보기

정적 파일이므로 아무 HTTP 서버로 열면 됩니다. (`file://`로 열면 데이터 fetch가 막힙니다.)

```bash
python3 -m http.server 8080
# http://localhost:8080
```
